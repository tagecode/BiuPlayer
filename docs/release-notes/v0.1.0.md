# BiuPlayer 0.1.0

博音音乐播放器首个 MVP 预览版。本地优先、离线可用、不采集遥测。

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `BiuPlayer_0.1.0_x64-setup.exe`（NSIS）、`BiuPlayer_0.1.0_x64-portable.zip`（绿色版） |
| macOS Intel | `BiuPlayer_0.1.0_x64.dmg` |
| macOS Apple Silicon | `BiuPlayer_0.1.0_aarch64.dmg` |
| Linux x64 | `BiuPlayer_0.1.0_amd64.AppImage`、`.deb`、`.rpm` |

校验文件：`SHA256SUMS.txt`。

## 亮点

- 7 种格式本地播放，播放队列与 4 种播放模式。
- 目录扫描支持暂停、取消、断点续扫和增量跳过。
- 专辑/艺术家浏览、拼音搜索、内嵌封面。
- LRC 同步歌词与桌面置顶歌词窗口。
- 系统托盘、单实例、关闭到托盘。

## 注意

- 未签名、未公证。macOS 首次打开请右键“打开”，或执行：
  `xattr -dr com.apple.quarantine /Applications/BiuPlayer.app`
- Windows 可能触发 SmartScreen，选择“更多信息 → 仍要运行”。
- 绿色版依赖系统 WebView2；Win10 1809+ 通常已自带，缺失时请安装 Evergreen WebView2 Runtime。
- AppImage 需要 FUSE2；无 FUSE 时可用 `--appimage-extract-and-run`。
- 这是预览版，请先备份曲库；卸载不会删除你的音乐文件。

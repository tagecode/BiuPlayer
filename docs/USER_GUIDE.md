# BiuPlayer 用户手册（MVP）

本手册对应 0.1.0 MVP：本地音乐播放、媒体库、播放列表、歌词、界面与设置。
不含 CUE、Gapless、标签写入、换肤、插件、EQ、系统媒体控制等 P1 能力。

## 1. 第一次启动

1. 打开 BiuPlayer，首页是「正在播放」。
2. 左侧进入「媒体库」，点「添加音乐目录」或「浏览…」选择文件夹；
   也可以直接把文件夹或音频文件拖进窗口。
3. 首次扫描会建立索引，扫描期间可以继续操作；状态条显示已扫描/新增/跳过数量。
4. 扫描可以在进度条旁「暂停」「取消」「继续」；取消后再次点「继续」会从
   上次位置续扫，不会重复入库。

支持的格式：MP3、FLAC、WAV、AAC/M4A、ALAC/M4A、OGG、AIFF。
文件按内容探测，扩展名写错的文件也能识别；损坏文件会跳过并写入日志。

## 2. 浏览媒体库

媒体库顶部有六个视图：

- **歌曲**：全部曲目，虚拟滚动，支持按标题/艺术家/专辑/添加时间/时长/路径/手动排序。
- **专辑**：封面网格，点开进入专辑详情。
- **艺术家**：按艺术家聚合。
- **专辑艺术家**：按「专辑艺术家」标签聚合；没有该标签时回退到曲目艺术家。
- **流派 / 年代**：按流派、年份聚合。
- **文件夹**：按扫描根目录聚合，可移除目录（只删索引，不删文件）。

列表过长时底部出现「加载更多」，分批渲染，避免一次卡住界面。

## 3. 搜索与拼音

顶栏搜索框（或媒体库内搜索框）支持：

- 标题、艺术家、专辑、文件名；
- 拼音全拼（`qingtian`）、首字母（`qt`）、首字母连写（`zjl`）；
- 中文按字面匹配。

拉丁字母查询按拼音命中时整行标题会高亮；中文查询按字面高亮。
搜索是即时的，输入后无需回车。

## 4. 播放

- 双击曲目或点「播放」开始播放；底部播放栏提供上一首/播放暂停/下一首/进度/音量/静音。
- 播放模式：顺序、列表循环、单曲循环、随机；模式会随队列一起保存。
- 队列面板可以查看当前队列；「下一首播放」会把曲目插到当前曲目之后。
- 关闭窗口默认最小化到托盘；托盘菜单可播放/暂停、切歌、显示主窗口、退出。
- 输出设备在「设置 → 音频」中选择；拔掉 USB 设备后会自动回退到默认设备并提示。
- 重新启动后会恢复上次的曲目、进度、队列与输出设备（可在设置中关闭「启动时恢复播放」）。

## 5. 播放列表

- 「播放列表」中新建/重命名/删除列表。
- 列表内可拖动行排序、多选、批量移除、撤销上一步。
- 顶部「名称 A→Z / Z→A / 默认顺序」可整体排序（会写回列表顺序）。
- 曲目右键或行内按钮可「加入播放列表」「下一首播放」。

## 6. 歌词

- 优先加载音频同目录下的 `.lrc`（大小写均可），其次读取文件内嵌歌词。
- 支持 UTF-8、UTF-16、GBK 编码；支持 `[offset:±ms]`、多时间标签与增强标签。
- 播放页逐行高亮并自动滚动；点击任意歌词行会跳转到该时间。
- 「设置 → 歌词」可调歌词偏移（正数提前、负数延后）与桌面歌词字号/颜色。
- 桌面歌词是独立置顶小窗，可从播放页「桌面歌词」按钮开关。

## 7. 设置

设置分八类：通用、播放、音频、歌词、界面、媒体库、数据、关于。

- 通用：语言（简中/繁中/英文，立即生效并写入配置）、主题（浅色/深色/跟随系统）、启动时最小化（需重启）。
- 播放：启动时恢复播放、默认播放模式。
- 音频：输出设备、独占/位完美（实验）。
- 歌词：偏移、桌面歌词字号与颜色。
- 界面：侧栏宽度/折叠、置顶、窗口透明度。
- 媒体库：排除规则（每行一个 glob）、监听目录（P1）。
- 数据：数据目录、缓存目录、便携模式开关、清理缓存。
- 关于：版本、构建 commit、Tauri 版本、许可与第三方组件、检查更新（仅打开外链）。

主题切换会同步写回 `settings.json`；首次绘制前就应用主题，避免白闪。

## 8. 便携模式

在「设置 → 数据」勾选「便携模式」会在程序目录写入 `portable.flag`，
之后配置、数据库、缓存、日志都放在 `<程序目录>/data`，可整个目录拷走。
删除该文件即回到系统标准目录（`%APPDATA%`、`~/Library/Application Support`、
`$XDG_DATA_HOME`）。切换后需要重启。

## 9. 诊断与日志

- 日志按天滚动写入数据目录的 `logs/biu.log`。
- 「设置 → 关于 → 导出诊断包」会生成 zip，包含系统信息、设置、最近日志；
  路径、用户名、主目录会被替换为 `<data-dir>`、`<user>`、`<home>` 等占位符。
- 若上次异常退出，下次启动会提示，并可导出崩溃日志。

诊断包不包含音频文件与媒体库数据库。

## 10. 常见问题

**扫描很慢？** 首次扫描需要读取标签，之后按大小+修改时间增量跳过。
**某些歌没有封面？** 只读取内嵌封面；没有时显示占位图。
**换电脑后库丢了？** 便携模式下把整个程序目录拷走；标准模式请备份数据目录。
**托盘图标不见了？** 检查系统托盘折叠区；关闭窗口默认不退出程序。

## 1. 产品定位与设计原则

**一句话定位**：一款好看、好用、可换肤、可插件扩展的本地优先无损音乐播放器，覆盖千千静听的经典能力，并适配现代桌面系统。

**设计原则**

1. **离线可用**：除用户显式开启的在线功能外，全部能力断网可用；不登录、不强制联网、无遥测。
2. **数据自主**：音乐、标签、播放数据全部留在本地；数据库可导出、可重建、可迁移。
3. **原生音质**：音频解码与输出在 Rust 侧完成，不经过 WebView 的 `<audio>`，以支持无损、位完美、DSD 与低延迟。
4. **经典 + 现代**：保留千千静听的播放列表 / 歌词 / 均衡器 / 换肤等经典交互，视觉与交互现代化。
5. **可扩展**：皮肤与插件都是版本化的资源包 / 插件包，具备清单、权限与兼容性声明。
6. **克制合规**：只做本地播放器，不做版权内容分发、不内置盗版音源、不绕过 DRM。

**Idea 诉求映射**

| 1. 本地优先 / 离线优先 / PC 跨平台 / 无损 | 设计原则 1、3；A 播放内核；N 构建分发 |

| 3. 换肤 + 插件开发，好看又好用 | G 界面与皮肤；H 插件系统 |
| 4. GitHub Actions 三平台打包；Win 绿色版 + NSIS；mac Intel/ARM；Linux 老发行版与 deb/rpm | N 构建与分发；第 7 节兼容性风险 |
| 5. 标准开源项目，不签名不公证 | 第 8 节范围外第 5 条；F-REL-04/07；更新策略 F-NET-02 |

## 3. 详细功能清单

### A. 播放内核（AUD）

核心原则：解码与输出全部在 Rust 侧，前端只做状态与 UI。这是无损、DSD、位完美、无缝播放的前提。

| 编号 | 功能 | 说明 | 优先级 | 验收要点 |

| F-AUD-04 | 音频输出设备 | 设备枚举、切换、热插拔回退；Windows WASAPI、macOS CoreAudio、Linux ALSA/PulseAudio/PipeWire | P0 | 切设备即时生效，拔出后自动回退默认设备 |

## 6. 里程碑与优先级

### M0 · 技术验证（1–2 周）
- Rust 解码（Symphonia + APE/DSD 方案）与输出（cpal/WASAPI/CoreAudio/ALSA）打通
- Tauri 2 壳 + React 界面最小闭环：能播放本地 FLAC/MP3，能读标签
- 验证 Linux 22.04 的 WebKitGTK 4.1 兼容性、20.04 探测、macOS 未签名分发路径
- **出口**：三平台各跑通一首无损播放；性能与体积数据出炉

### M1 · MVP（P0，约 6–8 周）
- 播放内核基础、播放列表、媒体库扫描与视图、基础歌词、基础皮肤（深浅色）
- 设置中心、托盘、单实例、便携模式、日志与崩溃处理
- GitHub Actions 三平台构建，产出绿色版/NSIS/dmg/AppImage+deb+rpm
- **出口**：普通用户可日常使用；安装包可下载；核心路径无阻断缺陷

### M2 · 1.0 对齐千千静听（P1，约 8–12 周）
- 均衡器、桌面歌词、歌词编辑、标签批量编辑、CUE、Gapless、位完美
- 换肤引擎 + 皮肤包、插件 API 与示例、文件关联、系统媒体控制、睡眠定时

- **出口**：第 3 节 P1 项全部完成；可对外发布 1.0（对照表见第 4 节）

## 7. 关键风险与待确认项

| 风险 | 影响 | 应对 / 待确认 |
|---|---|---|
| Tauri 2 依赖 WebKitGTK 4.1，Ubuntu 20.04 官方源仅有 4.0 | 可能无法在 20.04 构建/运行 | 尽早在 20.04 验证；备选：打包运行库进 AppImage、调整最低版本为 22.04，或评估 Tauri 1 |
| 不签名 / 不公证 | macOS Gatekeeper 拦截、Windows SmartScreen 警告 | 文档给出右键打开与 `xattr -dr com.apple.quarantine` 指引；提供 SHA256 与构建溯源 |
| Tauri 依赖 WebView2 | Windows 绿色版在无 WebView2 环境不可用 | 检测并引导安装；绿色版可附 fixed-version runtime 说明 |
| 千千 `.ski` 皮肤格式 | 格式逆向与授权风险 | P2 立项评审，默认自研皮肤格式 |
| DSD / 位完美依赖声卡与驱动 | 部分设备不可用 | 自动检测并回退 PCM，UI 明示实际输出 |
| APE/TTA/TAK 解码性能与稳定性 | 高码率卡顿 | 基准测试，必要时引入专用解码库 |
| 插件运行时选型（动态库 / WASM / JS） | 安全性与兼容性 | M2 前完成选型 ADR，优先 WASM 沙箱 |
| Winamp2 DSP 仅提供 32 位 DLL | 64 位主程序无法直接加载；需 32 位宿主与音频桥 | 独立 `biu-winamp-host.exe`（i686）+ 共享内存；仅 Windows x64，ARM64 实验性 |
| 10 万曲库扫描与数据库性能 | 启动慢、卡顿 | 增量扫描 + 索引 + 虚拟滚动，基准先行 |
| 播放统计/评分等数据迁移 | 升级丢数据 | 版本化迁移 + 自动备份 |

## 8. 范围外（明确不做）

1. 在线版权曲库、付费音乐分发、内置盗版音源或搜索下载。
2. DRM 解密、破解、去广告等灰色能力。
3. 账号体系、云同步、社交、评论、榜单运营。
4. 移动端（Android/iOS）与 Web 版。
5. 代码签名与 Apple 公证（成本原因，明确不做，改为校验与文档说明）。
6. 自建在线歌词/封面服务器（仅支持可配置的第三方源，用户自选）。
7. 遥测、埋点、崩溃自动上报（仅本地日志，用户主动导出）。

## 9. 附录：技术选型建议（非约束）

| 能力 | 建议方案 | 备注 |
|---|---|---|
| 解码 | Symphonia（MP3/AAC/FLAC/ALAC/OGG/WAV/AIFF）、APE/TTA/TAK/DSD 专用 crate | 统一封装为 Decoder trait |

| 文件监控 | notify | 防抖合并事件 |
| 歌词 | 自研 LRC 解析（兼容增强格式） | 便于双语与偏移 |
| 前端状态 | React + Zustand/Jotai | 播放状态以 Rust 事件为准 |
| 样式/皮肤 | CSS 变量 + 九宫格资源 + manifest | 皮肤包 zip |
| 快捷键/托盘 | tauri-plugin-global-shortcut、tauri-plugin-single-instance | 官方插件 |
| 日志 | tracing + tracing-appender | 滚动与诊断包 |
| 测试 | cargo test + vitest + Playwright（可选） | CI 质量门 |
| 发布 | tauri-action + GitHub Actions matrix | draft release |

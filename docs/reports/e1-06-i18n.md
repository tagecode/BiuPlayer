# E1-06 三语 i18n

日期：2026-11-24
任务：E1-06（2 人日）
状态：**外壳与页面占位完成**（M0 验证台未迁移）

## 1. 方案

- `src/i18n.tsx`：轻量自研 i18n，不引入 i18next，减少 MVP 依赖。
- 三份资源：`zh-CN`（基准）、`zh-TW`、`en`。
- `MessageKey = keyof typeof zhCN`；另两份资源声明为 `Record<MessageKey, string>`，**缺 key 直接 TypeScript 编译失败**。
- `I18nProvider` 保存当前语言到 `localStorage["biu.lang"]`，同步 `document.documentElement.lang`。
- `useI18n()` 暴露 `lang`、`setLang`、`t(key)`；key 为字面量类型，避免拼写错误。
